## 为什么选择本指南？

系统设计面试是顶级公司技术面试中最具挑战性的部分。本指南提供：

- **结构化框架** — 应对任何设计问题的分步方法
- **ASCII 架构图** — 可在白板上绘制的可视化架构
- **权衡分析** — 不只一个答案，而是多种方案及优缺点
- **容量估算** — 真实数字让你的设计更加具体
- **双语内容** — 每个文件都有完整中文版本

## 使用指南

### 面试准备

```
第一步：阅读 concepts/fundamentals.md 打好基础
第二步：学习每个概念文件（共 2-3 小时）
第三步：练习系统设计（每个 1-2 小时）
第四步：计时练习——目标每个设计 45 分钟
第五步：回顾权衡分析，练习解释决策
```

### 面试当天

```
┌─────────────────────────────────────────────────┐
│              45 分钟面试结构                      │
├─────────────────────────────────────────────────┤
│                                                 │
│  0-5 分钟    需求澄清                              │
│                                                 │
│  5-10 分钟   高层设计                               │
│                                                 │
│  10-25 分钟  深入核心组件                            │
│                                                 │
│  25-35 分钟  扩展性与权衡分析                        │
│                                                 │
│  35-45 分钟  监控与故障场景                          │
│                                                 │
└─────────────────────────────────────────────────┘
```

### RESHADED 框架

本指南中每个设计都遵循 **RESHADED** 框架：

```
R - Requirements       需求分析
E - Estimation          容量估算
S - Storage design      存储设计
H - High-level design   高层设计
A - API design          API 设计
D - Detailed design     详细设计
E - Evaluation          评估权衡
D - Distinctive component  差异化组件
```
