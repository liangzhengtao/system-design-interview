## なぜこのガイドなのか？

システム設計面接は、トップ企業の技術面接で最も挑戦的なパートです。本ガイドでは以下を提供します：

- **構造化されたフレームワーク** — あらゆる設計問題に対するステップバイステップのアプローチ
- **ASCII アーキテクチャ図** — ホワイトボードに描ける可視化されたアーキテクチャ
- **トレードオフ分析** — 一つの答えだけでなく、複数のアプローチとその長所・短所
- **容量見積もり** — 実際の数字で設計を具体的に
- **バイリンガル対応** — すべてのファイルに完全な中国語版を用意

## 使い方

### 面接準備

```
Step 1: concepts/fundamentals.md を読んで基礎を固める
Step 2: 各概念ファイルを学習（合計 2〜3 時間）
Step 3: システム設計を練習（各 1〜2 時間）
Step 4: タイム計測 — 各設計で 45 分を目標に
Step 5: トレードオフを復習し、意思決定の説明を練習
```

### 面接当日

```
┌─────────────────────────────────────────────────┐
│           45分間の面接構成                         │
├─────────────────────────────────────────────────┤
│                                                 │
│  0-5 分     要件定義                              │
│                                                 │
│  5-10 分    ハイレベル設計                         │
│                                                 │
│  10-25 分   コアコンポーネントの深掘り               │
│                                                 │
│  25-35 分   スケーリング＆トレードオフ              │
│                                                 │
│  35-45 分   監視＆障害シナリオ                     │
│                                                 │
└─────────────────────────────────────────────────┘
```

### RESHADED フレームワーク

本ガイドの各設計は **RESHADED** フレームワークに従います：

```
R - Requirements       要件分析
E - Estimation          容量見積もり
S - Storage design      ストレージ設計
H - High-level design   ハイレベル設計
A - API design          API 設計
D - Detailed design     詳細設計
E - Evaluation          トレードオフ評価
D - Distinctive component  差別化コンポーネント
```
